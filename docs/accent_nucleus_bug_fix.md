# アクセント核位置バグの修正

## 発見されたバグ

**問題**: アクセント核マーカー（↓）の位置が1つずれていました。

### 具体例

**「こんにちは、世界。」** の場合:

#### 修正前（バグあり）
```
音素: k o N n i ch i w a s e k a i
アクセント核位置: [9, 11]
出力: [N] [M5] k o N n i ch i w a [P1] [N] [M3] s ↓ | # [BG] e k ↓ a i [P2]
```
- 「こんにちは」(ko N ni chi wa): `s ↓` ← **間違い**（sは次の単語）
- 「世界」(se ka i): `k ↓` ← **間違い**（kは2モーラ目の子音）

#### 修正後（正しい）
```
音素: k o N n i ch i w a s e k a i
アクセント核位置: [8, 10]
出力: [N] [M5] k o N n i ch i w a ↓ [P1] [N] [M3] s | # [BG] e ↓ k a i [P2]
```
- 「こんにちは」(ko N ni chi wa): `a ↓` ← **正しい**（5モーラ目の最後）
- 「世界」(se ka i): `e ↓` ← **正しい**（1モーラ目の最後）

## 原因

`src/smalltts/data/phonemization/phonemes.py` の289-290行目:

```python
# バグのあるコード
if i + 1 < len(mora_positions) and mora_positions[i + 1] != mora_pos:
    result['accent_nuclei'].append(i + 1)  # ← i+1ではなくiが正しい
```

アクセント核が検出された時、「次の音素のインデックス（i+1）」を追加していましたが、
正しくは「現在の音素のインデックス（i）」を追加すべきでした。

## 修正内容

```python
# 修正後のコード
if i + 1 < len(mora_positions) and mora_positions[i + 1] != mora_pos:
    result['accent_nuclei'].append(i)  # 修正: i+1 → i
elif i + 1 == len(mora_positions):
    result['accent_nuclei'].append(i)  # 修正: i+1 → i
```

修正ファイル:
- `src/smalltts/data/phonemization/phonemes.py` (2箇所)
